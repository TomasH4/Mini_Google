# FINAL
## Comparativo - Lenguajes – PF
**By:** JuanGui

Tomar como referencia el Proyecto que definimos en clase e implementar una solución funcionalmente equivalente en Java, Scala y un tercer lenguaje de su elección.

El propósito no consiste únicamente en desarrollar tres versiones del mismo programa, sino en diseñar y ejecutar un proceso experimental que permita obtener métricas reales, comparar resultados y determinar automáticamente cuál de los tres lenguajes presenta el mejor comportamiento para el problema seleccionado.

Tener como base los principios de programación funcional, que vimos durante todo el semestre. Al finalizar, cada grupo deberá demostrar con evidencia cuantitativa y análisis técnico cuál alternativa resulta más conveniente para su proyecto.

## 2. Condiciones
1. Implementar el proyecto seleccionado en Java, Scala y un tercer lenguaje.
2. Garantizar los mismos requisitos funcionales y resultados equivalentes en las tres implementaciones.
3. Incorporar funciones de orden superior, expresiones lambda, transformación, filtrado, agrupación, reducción y otras operaciones funcionales pertinentes.
4. Diseñar escenarios de prueba para diferentes volúmenes de información o cargas de trabajo.
5. Implementar mecanismos para medir y registrar el comportamiento de cada solución.
6. Ejecutar pruebas bajo condiciones equivalentes para los tres lenguajes.
7. Consolidar los resultados en una estructura que permita compararlos.
8. Implementar un mecanismo que determine automáticamente el lenguaje con mejores resultados.
9. Presentar una clasificación con las métricas que justifican cada posición.
10. Generar una conclusión técnica sobre ventajas y limitaciones identificadas.

## 3. Comparar

| Criterio | Descripción | Peso |
| :--- | :--- | :---: |
| **Tiempo de ejecución** | Duración de las operaciones | 25% |
| **Consumo de memoria** | Memoria utilizada durante la ejecución | 20% |
| **Rendimiento** | Operaciones procesadas por unidad de tiempo | 20% |
| **Calidad de Código** | Evaluación de calidad de código | 15% |
| **Confiabilidad** | Correctitud y manejo de errores | 10% |
| **Uso Funcional** | Adaptación funcional | 10% |

> Las métricas cuantitativas deberán obtenerse mediante instrumentos de medición; los criterios cualitativos deberán evaluarse mediante reglas explícitas y verificables.
